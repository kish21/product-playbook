# Security policy

## Reporting a vulnerability

Please report a vulnerability in {product} privately, never in a public issue: on GitHub, open the
repository's **Security** tab and choose **Report a vulnerability**. We reply within 5 working days and
tell you when the fix ships.

## What we care about most

Any secret in the repository, a way to read another user's data, a login bypass, and (for an AI feature)
an instruction hidden in user content that changes what the product does.

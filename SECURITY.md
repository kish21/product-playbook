# Security

product-playbook is a set of skills and small local scripts (Python standard library only) that run inside your
coding agent, on your computer. It calls no outside service of its own and sends nothing anywhere: its only network
request is `/foundation` checking that your own app, started on your machine, answers. What your agent sends to its
model is between you and your agent.

## Reporting a problem

Please report security problems privately, not in a public issue: on GitHub, open the **Security** tab of this
repository and choose **Report a vulnerability**. You will get an answer within a few days.

## Supported versions

Only the latest release is supported; fixes ship as a new version on GitHub.

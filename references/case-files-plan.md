# Case files — /plan

War stories behind the one-line lessons in `commands/plan/SKILL.md`. Each heading is pointed to from the
skill file as `(case file: <heading>)`.

## The URL nobody scheduled

M1's exit criterion was *"a diner opens it on a different phone"*. That needs a public URL, and no milestone
scheduled one. The criterion was perfectly testable and unreachable for months.

## The timeline nobody was asked for

A logged run on a non-Claude model asked the owner nothing, wrote "4–6 weeks" with no dates, and ignored
that building could not start before a running experiment's due date. The skill named the constraints
("the timeline and the ordering are the user's constraints") but not the questions, so the run treated them
as its own to decide. The four questions in Step 2 are the fix.
